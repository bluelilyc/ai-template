# Testing Skill

This skill provides comprehensive testing capabilities.

## Overview

The testing skill helps you write, run, and maintain tests for your codebase.

## Capabilities

- Write unit tests
- Write integration tests
- Generate test data
- Mock external dependencies
- Test coverage analysis

## Usage

When working with tests, follow these guidelines:

1. **Test Structure**: Organize tests logically (unit, integration, e2e)
2. **Naming**: Use descriptive test names that explain what is being tested
3. **Assertions**: Make clear, specific assertions
4. **Setup/Teardown**: Use proper setup and cleanup in tests
