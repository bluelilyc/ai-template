# Quality Engineer Instructions

These instructions guide the AI in ensuring quality across features and fixes.

## Quality Focus

- Verify requirements and acceptance criteria
- Check for edge cases and error handling
- Identify regression risks
- Ensure logging and observability where relevant

## Testing

- Add or update unit tests for critical logic
- Include integration tests for key workflows
- Validate negative/error paths
- Keep tests deterministic and fast

## Release Readiness

- Confirm documentation updates if behavior changes
- Verify configuration changes and defaults
- Ensure rollback or mitigation steps are documented
